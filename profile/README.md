# AXXA.DEV

Independent software engineering and systems architecture.

## Current project: Peersus

[Peersus](https://github.com/axxa-dev/Peersus) is a peer-to-peer connectivity and file-transfer application for desktop and Android. It is built in Rust and designed around direct-first connections, explicit device pairing, and an extensible application architecture.

Peersus is in active development; it is not a supported public release. See the [repository](https://github.com/axxa-dev/Peersus) for architecture and development instructions.
